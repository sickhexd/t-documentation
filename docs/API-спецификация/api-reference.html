Описание API

Назначение API​

API спроектировано на основе двух Use Case: UC-4 (Бронирование парковочного места) и UC-5 (Выбор тарифного плана).

Связанная схема​

Эндпоинты REST API​

МетодПутьОписание
GET/api/parkingПолучение списка доступных парковочных мест
GET/api/parking/{place_id}/tariffsПолучение доступных тарифов по выбранному месту
POST/api/parking/reserveБронирование парковочного места
